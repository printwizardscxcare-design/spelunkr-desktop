This adds an explicit **None** option under **Captions → Caption engine**.

- Choose **None** to clear the subtitles and stop audio capture and speech recognition.
- Choose **Built-in captions (Whisper)** to start captions. Windows 11 users can also select Windows Live Captions.
- **Ctrl+Shift+L** on Windows/Linux or **Command+Shift+L** on Mac still toggles captions using your last-used engine. The menu shows None while captions are off.

Captions start off when the app opens. Color, size, recognition speed, and the last-used engine are still remembered.

Use the installer for your computer in the files below. [Windows setup](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/WINDOWS.md) · [Mac setup](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/MAC.md) · [Linux setup](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/LINUX.md).

This is still a preview. Windows installers are unsigned, and Mac apps aren't Apple-notarized. Mac live speaker capture and its permission flow still need a physical-Mac test. See [testing notes](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/TESTING.md) and the [caption guide](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/CAPTIONS.md).
