**Older Windows preview.** For current Windows, Mac, and Linux downloads, use [0.6.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.6.0).

This version added captions over the video, using text from Windows Live Captions.

Press **Ctrl+Shift+L** while the app has focus. The overlay shows text on a transparent background with a dark shadow, and **Captions → Text color** lets you choose white or yellow. The app remembers the color and keeps captions inside the video in windowed and fullscreen views.

Windows' caption window is minimized after the app connects to it. First use may take several seconds while Windows finishes its speech-file setup. **Captions → Open Windows caption window** opens the original controls when you need them.

Captions require **Windows 11 22H2 or newer**. Windows can caption other PC audio too. The wrapper doesn't save audio or transcripts, and Windows updates can affect the connection to its caption window.

Automated checks passed, and live caption updates, both colors, and video fullscreen were checked locally. Install the attached unsigned Windows x64 `Setup.exe`; its checksum is in `SHA256SUMS.txt`.
