This release adds native Mac apps for Intel and Apple Silicon and includes Whisper captions on Windows, Mac, and Linux.

- Windows 10 and Windows 11 now both have built-in English captions. Windows Live Captions remains an optional Windows 11 engine under Captions → Caption engine.
- Mac downloads come in Intel (`x64`) and Apple Silicon (`arm64`) versions. Both require macOS 14.2 or newer. Open the DMG and drag the app to Applications.
- Debian, Arch, and Fedora packages now use the same Whisper engine.
- English base and tiny models are included. Faster recognition is the default; Balanced is available for the larger model. No model download, speech account, Python installation, or subscription is needed.
- Speech detection filters silence before recognition. Captions keep the transparent background, white/yellow text, size choices, two-line blocks, pause clearing, and fullscreen channel arrows.

[Mac installation and audio permission](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/MAC.md) · [Linux installation](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/LINUX.md)

Use Ctrl+Shift+L for captions on Windows/Linux, Command+Shift+L on Mac. Fullscreen is F11 on Windows/Linux and Control+Command+F on Mac. Up and Down change channels while fullscreen.

Recognition runs locally and captures default speaker output, including other applications. No microphone is selected and no audio or transcript is saved. Live captions arrive in short batches; speed and accuracy depend on the computer and audio. Linux always-on-top remains unavailable in native Wayland sessions.

The Mac preview is signed locally but isn't notarized by Apple; macOS may require Open Anyway in Privacy & Security. See the Mac instructions before installing. Windows installers remain unsigned. Downloads require repository access while this project is private.

Build checks exercise bundled speech models and streaming PCM recognition. Linux packages also have installation, speaker-monitor capture, and X11 startup checks. Mac builds check signatures and startup on Intel and Apple Silicon. Hosted tests do not verify Mac audio-permission prompts or physical speaker devices; Mac live capture still needs a physical Mac test. Windows 10 compatibility targets its supported audio APIs and is not a claim of a separate Windows 10 hardware test.

Checksums accompany the downloads. The download-count report now includes Mac DMG files as well as Windows and Linux installers, with no app telemetry.
