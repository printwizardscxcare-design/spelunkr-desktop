**Older Windows preview.** For current Windows, Mac, and Linux downloads, use [0.6.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.6.0).

This fixes Windows Live Captions starting invisibly in 0.1.0. The app now opens a visible Windows caption window using normal Windows application activation.

Install the attached Windows x64 `Setup.exe`, open Spelunkr Desktop, and press **Ctrl+Shift+L**, or choose **Captions → Start Windows Live Captions**. The app needs keyboard focus. Windows' own system-wide shortcut is **Windows+Ctrl+L**.

This version opens the separate Windows caption window. The in-app overlay was added in 0.2.0.

Live Captions requires **Windows 11 22H2 or newer**. The visible window was checked on Windows 11 and the automated app checks passed. The installer is unsigned; its checksum is in `SHA256SUMS.txt`.
