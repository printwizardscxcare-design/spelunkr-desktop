Controls and fullscreen now work the same way throughout the app, and captions have better pause handling and a saved timing adjustment.

## What's changed

- Up/Down changes channels in both windowed and fullscreen views. Left/Right adjusts volume.
- Settings → Controls lets you assign keyboard shortcuts and controller buttons, triggers, and stick directions. Click Assign, press your control, then Save when you're done. Cancel discards the draft. The window uses the site's fonts, colors, and button styles.
- The fullscreen menu, shortcut, and video button use video fullscreen. A visible Exit fullscreen button and Escape return you to the window.
- Captions start off. None stops caption capture and recognition. Turning captions on rewinds 15 seconds once; speed changes and channel switches don't rewind again.
- Subtitle delay adds 0–10 seconds in 0.1-second steps. Text and silence clearing shift together. The setting is saved.
- Built-in Whisper captions now read the channel audio ahead of the picture and cache timestamped subtitles. Playback pauses for preparation, then resumes once at least 15 seconds are ready. The overlay follows video time, including pauses and seeks. If recognition falls behind, playback waits for the cache instead of letting subtitles drift late.
- Tape-audio cleanup removes offsets that can interfere with speech detection without changing the media clock.
- White/yellow text, transparent backgrounds, five text sizes, and wider fullscreen two-line blocks remain available.

## Before you install

This is an unofficial preview. Generated words and their estimated timestamps can be imperfect. Preparing the read-ahead cache needs an internet connection and can take longer on large Archive files. Subtitle delay adjusts when cached cues appear. Built-in captions use only the channel file, work when the player is muted, and don't need microphone or system-audio recording permission. Audio and transcripts aren't saved. Windows Live Captions remains an optional live system-audio engine.

Windows installers are unsigned. Mac apps are signed locally but aren't notarized by Apple. Physical gamepad hardware, full viewing on physical Macs, and every Linux desktop haven't been tested. See [testing notes](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/TESTING.md) for the checks and limits.

SHA-256 checksum files are attached for every platform. Install the package for your computer rather than the Source code ZIP.
