Captions now get a head start on the video. Whisper reads ahead and prepares a 15-second subtitle buffer before playback resumes, so it doesn't have to chase the picture.

## What's changed

- Captions follow the video when you pause or skip. If recognition falls behind, playback waits for more subtitles.
- Captions start off. Turning them on rewinds 15 seconds once and prepares the buffer. Choose None or use the same shortcut to turn them off.
- Subtitle delay is adjustable from 0–10 seconds and is saved between launches.
- Up/Down changes channels; Left/Right adjusts volume, in both windowed and fullscreen views.
- Settings → Controls lets you assign keys, controller buttons, triggers, and stick directions. Click Assign, press the control you want, then Save.
- The fullscreen menu, shortcut, and video button now use the same mode. Escape or Exit fullscreen brings you back.
- Audio cleanup helps Whisper recognize speech in older tape recordings. White or yellow text, five sizes, and a transparent background are still available.

## Install

Choose the download for your computer from the assets below. Both English speech models are included.

- **Windows 10/11, 64-bit:** Open the Setup.exe and follow the installer.
- **Mac, macOS 14.2+:** Choose arm64 for Apple Silicon or x64 for Intel. Open the DMG and drag the app into Applications.
- **Debian, Arch, or Fedora, 64-bit:** Install your distribution's package using the [Linux instructions](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/LINUX.md).

Use an installer rather than GitHub's Source code ZIP. SHA-256 checksum files are included.

## A few things to know

This is an unofficial preview. Whisper can get words and timing wrong, and preparing captions may take longer on a slow connection or computer. It reads the channel file directly, works with the player muted, and doesn't need microphone access. Audio and transcripts aren't saved. Windows Live Captions is still available as an optional alternative.

Windows installers are unsigned, and Mac builds aren't notarized by Apple. Full viewing on physical Macs and physical gamepad use still need testing. The [testing notes](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/TESTING.md) list the checks and remaining gaps.
