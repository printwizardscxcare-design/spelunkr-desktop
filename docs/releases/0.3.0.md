**Older Windows preview.** For current Windows, Mac, and Linux downloads, use [0.6.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.6.0).

This version added pause clearing, wider fullscreen captions, and a text-size menu.

- Captions clear after about 1.5 seconds without new recognized words. Text arriving in a batch can stay longer to allow reading time, up to four seconds.
- Case and punctuation corrections don't keep old text on screen. After clearing, captions resume with new words.
- Fullscreen text can use more of the screen width and scales with the display height.
- **Captions → Text size** offers 80%, 100%, 125%, 150%, and 200%. Size and white/yellow color choices are saved.

**Ctrl+Shift+L** toggles the transparent in-app overlay. This version estimates pauses from Windows' text updates; it doesn't detect silence directly from the audio.

Automated checks covered timing, stale text, fullscreen layout, and size settings. Pause clearing and saved size settings were also checked in the packaged Windows app.

Captions use Windows Live Captions and require **Windows 11 22H2 or newer**. Install the attached unsigned Windows x64 `Setup.exe`; its checksum is in `SHA256SUMS.txt`.
