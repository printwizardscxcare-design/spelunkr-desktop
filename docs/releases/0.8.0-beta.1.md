This beta includes an Audio panel and optional anonymous usage statistics. Open **Audio → Audio settings** for sound, or **Settings → Usage statistics** for reporting.

Usage reporting starts only after you opt in. It reports an anonymous installation ID, app version, operating system, and periodic activity to PostHog. The configured project retains approximate country and discards IPs and finer location data. No viewing history, audio, captions, or screen recordings are reported. You can opt out later; declining is remembered. See [usage reporting details](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/USAGE-STATS.md).

- **Normalization** smooths level changes across channels, shows, and commercials.
- **Denoiser** slider runs from Off to stronger tape-hiss reduction.
- **Compression and makeup gain** can be paired or adjusted independently. Choose **Pre EQ** or **Post EQ**.
- **Ten-band graphic EQ**, with bypass and a Flat EQ reset.
- **Classic presets:** Straight from the VCR, Channel Surfer, Living Room ’89, Rabbit Ears, The Late Late Show, and Hi-Fi Stereo. Save, update, or delete your own presets too.
- Your current sound and personal presets are remembered after quitting.
- Optional **Subtitle audio cleanup** uses a separate, unheard feed for Whisper. It is off by default: cleanup preserved speech and timing on the test sample, but did not improve its wording. Listening effects never change the recognition input.

The five-second subtitle cooldown after tuning remains included. Denoising is intended for steady noise; strong settings can soften music and voices. Presets are gentle starting points, not a promise to restore every tape. The new audio path has automated DSP, real Chromium audio/UI, and persistence checks. Wider listening tests are still needed.

Install the matching package below. Windows installers are unsigned; Mac builds aren't notarized. macOS 14.2+ is required. The beta installs over an existing copy; reinstall [0.7.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.7.0) to return to the current version. There is no automatic updater. This update replaces the previous 0.8.0-beta.1 installers at the maintainer’s request. The current 0.7.0 release remains available, and further changes stay in beta until a regular release is requested.
