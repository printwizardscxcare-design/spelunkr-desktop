This release adds Linux packages for Debian, Arch Linux, and Fedora on 64-bit Intel/AMD PCs.

- Debian: install the `.deb` with `sudo apt install ./<filename>.deb`.
- Arch: update with `sudo pacman -Syu`, then install the `.pkg.tar.xz` with `sudo pacman -U ./<filename>.pkg.tar.xz`.
- Fedora: install the `.rpm` with `sudo dnf install ./<filename>.rpm`.

[Linux installation and troubleshooting](https://github.com/printwizardscxcare-design/spelunkr-desktop/blob/main/docs/LINUX.md)

Linux captions use a bundled Vosk English speech model. Press Ctrl+Shift+L to enable them. They run locally and use the same transparent overlay, white/yellow text, size choices, two-line blocks, pause clearing, and fullscreen layout as Windows. The model and recognition runtime are included; Python and a speech account aren't needed. The package manager installs the speaker-capture utility. A running PulseAudio server or PipeWire with PulseAudio compatibility is required. Other apps' speaker audio can also appear in captions. No audio or transcript is saved.

F11 toggles fullscreen. Up and Down change channels in fullscreen. Always on top is unavailable in native Wayland sessions. Linux speech accuracy and language support differ from Windows Live Captions; this version supports English on Linux.

The Windows installer is included too. Windows captions still require Windows 11 22H2 or newer. All installers are unsigned. Downloads require repository access while the project is private.

SHA-256 checksum files are provided for Windows and Linux. Download counts include the new Linux packages, with no tracking added to the app.

The real packages passed installation, local speech recognition, speaker-monitor capture, capture cleanup, and X11 startup checks in Debian 13, Fedora 43, and current Arch containers. Physical desktop playback, Wayland compositors, and every sound-device combination have not been tested.
