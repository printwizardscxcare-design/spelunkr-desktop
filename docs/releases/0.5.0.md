**Older preview.** For current downloads and instructions, use [0.6.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.6.0).

This version added Linux installers for Debian, Arch, and Fedora on 64-bit Intel/AMD PCs. A Windows installer is included too. There is no Mac build in 0.5.0.

## Captions in this version

Linux captions use the included **Vosk English model**. Windows captions use **Windows Live Captions**, which needs Windows 11 22H2 or newer. The bundled Whisper engine was added later, in 0.6.0.

Press **Ctrl+Shift+L** while the app has focus to toggle the transparent caption overlay. White/yellow text, size settings, two-line blocks, pause clearing, and fullscreen channel arrows are available.

Linux capture needs PulseAudio or PipeWire with PulseAudio compatibility. It listens to the default speaker output, including other apps. No audio or transcript is saved. The model and recognition runtime are bundled, so users don't need to install Python.

## Install 0.5.0 on Linux

Download the matching file below, then run its command from the download folder:

```sh
# Debian
sudo apt install ./Spelunkr-Desktop-0.5.0-Debian-amd64.deb
# Arch: update first, then install
sudo pacman -Syu
sudo pacman -U ./Spelunkr-Desktop-0.5.0-Arch-x64.pkg.tar.xz
# Fedora
sudo dnf install ./Spelunkr-Desktop-0.5.0-Fedora-x86_64.rpm
```

The packages passed installation, speaker-monitor recognition, cleanup, and X11 startup checks in Debian 13, Fedora 43, and current Arch containers. Always on top isn't available in native Wayland sessions. Physical desktop playback and every sound-device combination weren't tested.

The Windows `.exe` installs for your account. These installers are unsigned, and SHA-256 checksum files are included.
