**Older Windows preview.** For current Windows, Mac, and Linux downloads, use [0.6.0](https://github.com/printwizardscxcare-design/spelunkr-desktop/releases/tag/v0.6.0).

Captions now replace a whole two-line block when it fills. Earlier versions could keep adding words while the beginning scrolled away.

- Text is measured against the video width and selected size.
- Extra words wait for the next block, with a short reading hold before it appears.
- Windows' revisions to earlier text don't bring back blocks that have already been read.
- Resizing or entering fullscreen adjusts the words that still need to be shown.
- Turning captions on ignores the Windows caption window's earlier transcript and starts with newly recognized speech.

Use **Ctrl+Shift+L** to toggle captions. **Captions → Text size** and **Text color** keep the size and white/yellow choices introduced in earlier versions. Pause clearing and the transparent background remain available.

This version gets its text from Windows Live Captions, so captions require **Windows 11 22H2 or newer**. Changes to Windows' caption window can affect that connection. Whisper support for Windows 10 came later, in 0.6.0.

Caption timing, block replacement, overflow, resizing, and fullscreen behavior passed automated checks. The packaged app was also checked visually with live Windows captions in fullscreen.

Install the attached Windows x64 `Setup.exe`. It is unsigned; `SHA256SUMS.txt` contains its checksum.
