# Set up your controls

Open **Settings → Controls…**, or press **Ctrl+,** on Windows/Linux or **Command+,** on Mac.

Click **Assign** next to an action and press the key or controller input you want to use. Buttons, triggers, and stick directions work. Make your other changes, then click **Save** to apply them together. **Cancel** leaves your current controls alone.

Each action can have one keyboard shortcut and one controller input. Assigning an input already used elsewhere moves it to the new action. The × beside an assignment clears it. **Restore defaults** changes the draft; click Save to apply it.

## Defaults

| Control | Action |
| --- | --- |
| Up / Down, or controller D-pad up / down | Next / previous channel |
| Right / Left, or D-pad right / left | Volume up / down |
| Space, or bottom face button | Play / pause |
| M | Mute / unmute |
| R | Random channel |
| Shift+Left / Shift+Right | Rewind / forward 15 seconds |
| F11, or Control+Command+F on Mac | Video fullscreen on / off |
| Escape, or the Exit fullscreen button | Exit fullscreen |
| Ctrl+Shift+L, or Command+Shift+L on Mac | Captions on / off |

Escape stays available for exiting fullscreen. Settings and your computer's reserved shortcuts can't be reassigned.

The controls work in both windowed and fullscreen views. Click the app first. Typing in a text field leaves playback controls alone. Controllers need to be recognized by the operating system and Chromium's Gamepad API; remotes that send ordinary keys can use keyboard assignments.

The list includes playback, caption, window, and available page buttons. A saved page button works while that button is present. Controls are stored locally and carry over when you update the app.
